# Common Ground

Common Ground is a route-planning and data-storytelling app for turning places, events, and travel information into a clear, shareable journey.

## Current Stack

This repository currently uses React, TypeScript, and Vite. The original product brief proposed a framework-free static implementation; see [TECHNICAL_SPEC.md](TECHNICAL_SPEC.md) for that target and the difference from the current codebase.

## Getting Started

Requires Node.js and npm.

```sh
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Available Scripts

- `npm run dev` starts the development server.
- `npm run build` runs the TypeScript build and creates a production bundle.
- `npm run preview` serves the production bundle locally.
- `npm run lint` runs ESLint.
